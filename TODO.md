## 🔧 Как запустить (памятка)

```powershell
# Эмулятор с программным GPU (иначе глючит экранная клавиатура):
& "$env:LOCALAPPDATA\Android\Sdk\emulator\emulator.exe" -avd mama_pixel -gpu swiftshader_indirect

# Flutter-клиент на эмуляторе (OneDrive должен быть закрыт!)
cd C:\Users\yeren\OneDrive\Desktop\Projects\MaMa\app
flutter run -d emulator-5554

# Бэкенд
cd ..; docker compose up -d db redis; docker compose run --rm migrate
docker compose up api worker
```
